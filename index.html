BFMiDi Editor

Como podemos ajudar?

Sem instalar nada

O editor também roda direto no navegador: com o pedal ligado e o Wi‑Fi dele ativo, abra http://192.168.4.1 (rede BFMIDI_WIFI, senha bfmidi@editor) ou http://bfmidi.local na rede de casa. No computador, o Chrome ou o Edge também conectam pelo cabo USB pelo editor online.

Instalando no Windows

  1. Baixe o Setup.exe e abra.
  2. Se o Windows mostrar “O Windows protegeu o seu PC”, clique em Mais informações e depois em Executar assim mesmo. O aviso aparece porque o instalador ainda não tem certificado de assinatura; o app é o mesmo dos outros sistemas.
  3. O componente WebView2 (motor do Edge) é instalado automaticamente se faltar.
  4. Para atualizar, baixe o Setup novo e instale por cima. As preferências ficam guardadas.
